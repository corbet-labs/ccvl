# Private evidence workspace

This directory is where an AI agent builds the candidate's source-linked fact
base and visible interview journal. Start from `templates/profile.md` and
`templates/profile-journal.md`.

Evidence is private input, not publication material. The files are ignored by
default; keep them local or deliberately track them only in a private
standalone repository. The public `cvl/general/stations.json` contains only the
selected station plan and provenance references needed to validate the CV.
