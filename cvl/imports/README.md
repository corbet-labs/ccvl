# Private document inbox

Drop existing CVs, LinkedIn exports, diplomas, references, project notes, or
other source material here when that is easier than pasting or attaching it in
chat. An AI agent inventories and reads the material; ccvl does not upload it.

The contents are ignored by default. Tell the agent when files have been added
because this directory is not watched automatically. Keep originals read-only;
derived facts and unresolved conflicts belong in `../evidence/`.
