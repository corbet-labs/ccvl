# CV project

The DE-CH and EN-CH sources render exact two-, three-, and four-page presets.
The first two pages contain the core CV, page three adds projects, and page four
adds machine-readable capability and keyword coverage.

The Summary always comes from exactly five measured lines in
`tailored_cv.summary` in the selected `application.json`. The public default
combines a target-neutral open application with the adaptation formula
documented in `docs/summary.md`.
