# Targets

This top-level group holds the durable map of organisations, markets,
functions, and role families the candidate may pursue. It is independent of
any individual vacancy.

Use one clearly named Markdown or JSON record per target or target set. Keep
the dimensions MECE and preserve sources, dates, rationale, and priority. A
live vacancy belongs under `../opportunities/`, linked back to the relevant
target where useful.

The public ccvl repository intentionally contains only this scaffold. Personal
target research belongs in a private downstream.
